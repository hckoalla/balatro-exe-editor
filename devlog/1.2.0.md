# v1.2.0 — Batch editing, poker hand levels, and scoped resets

This update covers everything planned for v1.2 — batch editing, a poker hand editor, scoped
restores — plus a couple of things that only became obvious once the whole thing was actually put
through its paces.

## What's new

**Batch deck editing.** A new "Batch Deck Editor" tab lets you select multiple decks with
checkboxes and apply the same starting money, joker slots, consumable slots, and starting
consumables to all of them in one go. The values you enter replace whatever each deck already
had — no need to edit deck by deck when you want the same setup across several.

**Poker hand level editor.** A new "Poker Hand Editor" tab lets you edit every poker hand's base
chips/mult (its level 1 value) and how much it grows per level, individually. Straight Flush,
Full House, Two Pair — all 12, one form.

**Restore, but scoped.** Alongside the existing "restore everything" option, you can now restore
just your decks or just your poker hands, without touching whatever you customized elsewhere. If
you only want to undo one thing, you don't have to undo everything.

**A proper Settings tab.** The language switcher — previously tucked behind a small button on the
deck list — now lives in its own tab, next to the general restore button.

**Heads-up notes on the Challenge Deck.** Two informational notes, not warnings that block you:
one on Starting Money explains that the Luxury Tax challenge shrinks your hand size as money
piles up, so a high starting value there can make that specific challenge unplayable. One on
Joker Slots explains that a handful of challenges (Blast Off, Five-Card Draw, Cruelty, Jokerless,
Typecast) force their own joker slot count no matter what you set here — that's the game's own
challenge rules overriding the deck, not a bug in the editor.

**Confirmations now open in a modal.** Save and restore prompts used to push the rest of the
screen down when they appeared. Now they open in a centered dialog instead.

## A bug I caught before it caused confusion

While testing the poker hand editor, I found that editing a hand's starting value (`s_mult`/
`s_chips`) had no visible effect in-game — until you leveled that hand up once, at which point it
suddenly worked. Turned out the game only recalculates the value it actually scores with from the
starting value when a hand levels up; a fresh run just uses whatever was already there. The editor
now writes both, so your starting values apply immediately, without needing to level anything up
first.

## What's next

The safe ranges for starting money, joker slots, and consumable slots were tested empirically a
while back — but since those same numbers grow naturally over a normal run, there's a good chance
the real ceiling is higher than what was tested for a fresh start. That's next: a manual testing
pass to see how far these (and the brand-new poker hand fields, which don't have a tested limit
yet) can actually go.
