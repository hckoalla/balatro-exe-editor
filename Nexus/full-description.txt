[b][color=#d4d4d8][size=4]Description[/size][/color][/b]
[color=#D4D4D8]Balatro EXE Editor is a lightweight desktop tool that lets you customize the starting rules of every deck in Balatro — no manual file hacking, no 7-Zip, no text editor. Just point it at your [/color][color=#d4d4d8][font=Monaco, Menlo, Consolas, monospace][b]balatro.exe[/b][/font][/color][color=#D4D4D8], pick a deck, tweak the values, and save. It edits the game executable directly, with an automatic backup taken before your first change and a one-click "Restore Default" button if you ever want to go back to vanilla.[/color]

[b]Installation instructions[/b][/color]

[list=1]
[*][color=#D4D4D8]Download Balatro EXE Editor x.x.x.exe from the Files tab — it's a single portable executable, no installer.[/color][/*]
[*][color=#D4D4D8]Run it directly from wherever you saved it — no install step, nothing added to Program Files or the Start menu.[/color][/*]
[*][color=#D4D4D8]Point it to your balatro.exe[/color][color=#D4D4D8] (usually inside your Balatro install folder) — or let it detect a Steam install automatically.[/color][/*]
[*][color=#D4D4D8]Pick a deck, edit its values, hit Save.[/color][/*]
[/list]
[color=#D4D4D8]No files need to be copied into your Balatro folder — the app edits your existing [/color][size=2][font=Monaco, Menlo, Consolas, monospace]balatro.exe [/font][/size][color=#d4d4d8]in place, so keep it pointed at the real install.[/color]
[color=#D4D4D8][b]Main features[/b][/color]

[list]
[*][color=#D4D4D8]Edit all 16 decks individually (all playable decks + the Challenge deck) — not a single global value.[/color][/*]
[*][color=#D4D4D8]Customize starting money, joker slots, and consumable slots per deck.[/color][/*]
[*][color=#D4D4D8]Choose exactly which consumables (Tarots, Planets, Spectrals) each deck starts with — with the real in-game artwork for each one, and a hover tooltip showing a bigger image, name, and what it does.[/color][/*]
[*][color=#D4D4D8]Automatically detect your Balatro install via Steam, or point it to the .exe manually.[/color][/*]
[*][color=#D4D4D8]Automatic backup before your very first edit, plus a one-click restore to the game's original defaults.[/color][/*]
[*][color=#D4D4D8]Soft warnings when you push a value past the safe, tested range — you're told, never blocked.[/color][/*]
[*][color=#D4D4D8]Available in English, Portuguese (BR) and Spanish.[/color][/*]
[/list]

[b]Requirements[/b][/color]

[list]
[*][color=#D4D4D8]Windows only.[/color][/*]
[*][color=#D4D4D8]Close Balatro (and Steam's file lock on it) before saving changes — the app can't write to the .exe [/color][color=#D4D4D8]while it's open.[/color][/*]
[*][color=#D4D4D8]Nothing else to install — no dependencies, no Lua/Love2D tooling required on your end.[/color][/*]
[*][color=#D4D4D8]The app isn't code-signed (solo/fan project) — Windows SmartScreen may show a warning on first run ("Windows protected your PC"). Click "More info" → "Run anyway" — normal for small unsigned tools, not a sign of anything malicious.[/color][/*]
[*][color=#D4D4D8]Heads-up: Steam's "Verify integrity of game files" can silently revert your edited .exe[/color][color=#D4D4D8] back to the original. Re-apply your changes if that happens.[/color][/*]
[/list]
